# Address Variation Generator

Created by Midnightvandal.

Streamlit app that turns a real street address into batches of custom variations, with store-item first names and One–Twenty last names.

## Run it on your computer

```bash
pip install -r requirements.txt
streamlit run address_variator_app.py
```

On Windows, double-click `run_app.bat`.

The address box starts empty. Pick 50, 100, 250, 500, 1000, or 5000 variations, then download TXT or CSV from the page.

## Share a live link

1. Open [Streamlit Community Cloud](https://share.streamlit.io) and sign in with this GitHub account.
2. New app → repository `MIDNIGHTVANDAL/address-variation-generator` → main file `address_variator_app.py`.
3. Deploy. You get a public URL you can send to anyone.
4. Edit the files in this repo and push. The live app updates on its own.
